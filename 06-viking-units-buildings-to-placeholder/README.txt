Viking Placeholder Assets — Open Northland Content Mod

Import this ZIP in the current game's main menu under Mods.

This pack is data-only. It overrides bobs/atlases.json and supplies PNG sprite sheets
for the Viking tribe's active building and settler atlas bindings. Each non-empty
source bob frame is rendered as a solid coloured rectangle while retaining the
original atlas geometry and frame offsets. Other civilizations and game rules
are left untouched.

Palette:
- Viking buildings: orange / yellow variants
- Viking people: blue
- Shadow sheets: translucent dark blocks
- Vehicle-related sheets referenced by Viking building bindings: green

The pack intentionally contains an empty ir.json patch because the mod importer
requires that file; the atlas manifest is overlaid as a complete file.
